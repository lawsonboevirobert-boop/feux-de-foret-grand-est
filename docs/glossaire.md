# Glossaire

Les termes qu'on connaissait pas dans la commande + ceux de nos analyses. Doublons fusionnés.
Si on est pas sur de la définition -> statut "à vérifier".

| Terme | Définition | Vient de | Statut |
|---|---|---|---|
| SDIS | service départemental d'incendie et de secours, les pompiers du département. ici le SDIS 67 (Bas-Rhin) qui nous passe la commande | mail SDIS 67 | ok |
| CIS / chef de centre | centre d'incendie et de secours = une caserne. le chef de centre la dirige, c'est eux qui disent que le seuil marche pas | mail SDIS 67, analyse Denis | à vérifier |
| Météo des forêts | indice de danger de feu de foret publié par Météo-France pour chaque jour, par niveaux. c'est sur lui que le SDIS déclenche le renfort | mail SDIS 67, analyses Denis + Lawson | à vérifier (nb de niveaux, depuis quand il existe) |
| niveau de danger / seuil | le niveau de la Météo des forêts (faible, modéré, élevé, très élevé ?). le seuil c'est le niveau a partir duquel le SDIS lance le dispositif renforcé | mail SDIS 67, analyse Lawson | à vérifier |
| IFM (indice forêt météo) | le calcul derriere la Météo des forêts, a partir de la météo (temp, vent, humidité, pluie) | analyses Denis + Lawson | à vérifier |
| dispositif renforcé | les moyens en plus quand le risque est haut : patrouilles, guet... on sait pas ce que ca contient exactement dans le 67 ni combien ca coute par jour | mail SDIS 67 | à vérifier (demander au SDIS) |
| guet | surveiller pour repérer un départ de feu vite (tours de guet, postes en hauteur) | mail SDIS 67 | à vérifier |
| patrouille | équipe qui tourne dans les zones a risque pour voir les feux tot et intervenir | mail SDIS 67 | à vérifier |
| départ de feu | le début d'un incendie. question : on compte tous les départs ou seulement ceux qui deviennent des feux de foret ? | mail SDIS 67 | à vérifier |
| feu de foret | incendie qui touche une foret (ou lande, broussailles ?). a partir de quelle surface on le compte, ca peut changer d'une source a l'autre | analyse Denis | à vérifier |
| surface brulée | nb d'hectares touchés par un feu | analyse Denis | ok |
| fausse alerte | pour nous : un jour ou l'indice est au dessus du seuil mais aucun feu se déclare | mail SDIS 67, analyse Lawson | définition du groupe, a valider |
| feu manqué | pour nous : un jour ou l'indice est sous le seuil et un feu se déclare quand meme | mail SDIS 67, analyse Lawson | définition du groupe, a valider |
| BDIFF | base de données sur les incendies de forets en France, la liste des feux | analyses Denis + Lawson | à vérifier (ce qu'il y a dedans, depuis quand) |
| DFCI | défense des forets contre l'incendie (pistes, points d'eau, aménagements...) | analyse Lawson | à vérifier |
| interface habitat-foret | les endroits ou les maisons touchent la foret, la ou un feu est plus dangereux | analyse Lawson | à vérifier |
| saison feux | la période avec le plus de risque, surtout l'été. Lawson propose mars -> octobre | mail SDIS 67, analyse Lawson | à vérifier |
| COG | code officiel géographique de l'INSEE, les codes des communes. ca change chaque année (fusions de communes) donc faut savoir de quelle année est le code | analyse Denis, cours | ok |
